# ChatClone — تطبيق محادثة أندرويد مستقل

هذه نسخة أولية لواجهة محادثة عربية مستقلة. ليست نسخة رسمية من ChatGPT ولا تتصل به تلقائيًا.

## ماذا تعمل النسخة الحالية؟
- شاشة محادثة عربية.
- إضافة رسائل المستخدم إلى الشاشة.
- زر محادثة جديدة.
- رسالة توضيحية إذا لم يُضبط عنوان API.

## ما الذي لم يُنجز بعد؟
- الربط الفعلي بنموذج الذكاء الاصطناعي.
- حفظ المحادثات الدائم عبر Room.
- تحليل الصور ورفع الملفات.
- تسجيل الصوت وتحويله إلى نص.
- إعداد الخادم الخلفي والمصادقة.

## بناء APK من الهاتف عبر GitHub Actions
1. أنشئ مستودعًا جديدًا على GitHub من المتصفح في الهاتف.
2. ارفع جميع ملفات هذا المشروع إلى المستودع مع الحفاظ على المسارات.
3. افتح تبويب Actions وفعّل GitHub Actions إذا طُلب ذلك.
4. اختر workflow باسم Build Android APK ثم Run workflow.
5. بعد اكتمال البناء، افتح نتيجة التشغيل ونزّل artifact باسم `ChatClone-debug-apk`.
6. فك ضغط artifact ثم ثبّت `app-debug.apk` على جهاز أندرويد. قد تحتاج للسماح بالتثبيت من المصدر الذي نزّلت منه الملف.

## ملاحظات
- يحتاج البناء إلى اتصال إنترنت، وقد يتطلب إعداد Gradle Wrapper في المستودع. ملف workflow يستخدم Gradle المثبت على runner.
- لا تضع مفتاح API داخل تطبيق أندرويد أو مستودع عام. أضف خادمًا خلفيًا قبل ربط نموذج حقيقي.
- لا ترفع APK المرجعي أو ملفات خاصة لا تملك حق توزيعها.
